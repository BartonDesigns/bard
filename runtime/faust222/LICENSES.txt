Bard Character 222 uses a real Faust-compiled stereo DSP.
Compiler: Faust 2.88.0 via @grame/faustwasm 0.18.4 (build-time only).
https://github.com/grame-cncm/faustwasm
https://github.com/grame-cncm/faustlibraries

The original DSP and lightweight JavaScript host are MIT-licensed below.
Faust standard-library compiled output is used under the library compilation
exception and applicable permissive per-function terms. The generated metadata
(character222.json) lists the exact functions and author/license notices.
The Faust compiler and FaustWasm runtime library are not distributed in this
runtime folder. Our host calls the compiled DSP's public WASM exports directly.
