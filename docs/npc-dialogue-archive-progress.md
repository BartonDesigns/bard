# NPC dialogue separation, archive and tone

4 October 2026 Pacific. Branch: codex/npc-dialogue-archive. Base release: d45fda6 (PR #9).

Implemented: each NPC's stable ID owns its conversation archive; the Guide has its own thread. Switching people or views aborts pending work and resets the active transcript. Late Guide/NPC completions cannot change a newer conversation. Search and chronological per-person archive reading do not feed other people's messages into model context. New turns are retained independently of the short model/social context window. Existing retained turns migrate once; previously discarded messages cannot be recovered. Storage failures preserve existing saved bytes and new in-memory turns, with explicit export guidance. Conversations remain in this browser unless the player exports them; selected cloud providers receive their normal bounded request context.

Settings: clean/mature language, restrained/bold characterization, brief/balanced/rich responses. Mature adult NPCs may use natural profanity and discuss adult life themes, while remaining distinct and grounded. Child NPCs remain age-appropriate. The settings change prompts, not provider policies or supported game actions. Cloud support requires the separately prepared Worker deployment; the existing configured Worker is https://l99-discovery.joshbarton1921.workers.dev. The owner confirms it is deployed; this environment has no deployment credentials and its status probe returned HTTP 403, so the deployed version is not verified.

Universal world progression is NOT implemented by this archive. The owner clarified it as a requirement: shared world projects need authoritative server state, stable identities, idempotent contributions and reconnect/catch-up. Personal conversations should remain private. See BR-006 in docs/build-requests.md.

Verification: six archive tests cover full-history isolation/reload/search, import, quota/export and corruption preservation. Style tests cover normalization and age boundaries; 96 Worker assertions and its deployment dry-run pass; changed JS lint and production build pass. The actual two-NPC browser regression verifies separate visible/model histories, 41 retained archive turns versus 16 context turns, oldest-turn search, read-only archive, reopen and real reload, stale Guide reply rejection, saved mature/bold/rich settings and a 480×320 layout with zero page errors. All three style controls fit the small-screen settings view; closing settings restores the active NPC thread. Model responses are deterministic test fixtures, not live provider language-quality validation. Evidence: docs/verification/dialogue/.
