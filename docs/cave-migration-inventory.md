# Cave preservation and native Crysis migration inventory

Audit date: 2026-10-04. Baseline: `44bc21638444b0a1ed5a0c765b97e09c3af61a64`. This is a source audit, not a claim that every legacy mechanic has been migrated or browser-tested. No applicable `AGENTS.md` was found in the workspace search. Source changes made concurrently after this baseline may close some gaps below.

The canonical legacy artifact is **`runtime/caves-179.html.gz`**. All legacy symbols below are in its decompressed HTML; line numbers refer to that decompressed text. Reproduce with `gzip -dc runtime/caves-179.html.gz > /tmp/bard-caves-179.html`. Keep this artifact intact until the preservation matrix has verified replacements. `docs/flight-migration-catalog.json` additionally records surface-cave, excavation, shared-person, and black-hole cavern dependencies. The black-hole Final Cadence/Pupil route is a distinct flight story, not a replacement for the ordinary planetary cave system.

## Existing native foundation

Crysis already has a connected cave network: `island/src/planet/cavenet.js` (`planCaves`, `makeField`, `meshChunk`, `chunkKeys`) plans seeded chambers and hillside mouths, carves a signed rock field, and meshes that same field for rendering and collision. `island/src/planet/underworld.js` (`createUnderworld`, `stream`, `openHoles`, `rockFloor`, `rockRoof`, `push`) streams 24 m chunks into the **same scene/camera/player** as the surface. Entrance terrain holes wait for their mouth chunks. Geometry generation is budgeted and villages/ruins build lazily.

At this audit baseline, `island/src/main.js` disables the plan on Earth (`const cavePlan = earth ? null : planCaves(...)`) and creates the underworld only inside `if (!earth)`. This is a coverage gap, not a need to introduce a second renderer or route. The separate `island/src/caverns.js` builds underwater tubes, arches, skylights and bioluminescence, but is not the rich legacy underground world.

`island/src/planet/profile.js` already assigns distinct rock/glow/crystal/lava/ice/water parameters to world profiles. Cave civilization styles select native names and architecture. Preserve these distinctions when adding legacy content; do not substitute the same cave seed for every planet.

## Lore that should survive

Keep the exact legacy arrays with attribution to their source during extraction, not freshly paraphrased substitutes. The underground dwellers have five role pools: **elder, trader, parent, worker, child**. Core themes include water remembering rooms, stone breathing, old lamps predating inhabitants, towns as guests of mushroom light, folded light-folk, epoch weather, lantern routes, shared homes, currents carrying family messages and musical stone. The trader explicitly rejects coins. These themes support the user's requested world-development rewards.

Preserve `SOUL_LORE`, `VAULT_LORE`, the named depth milestones and procedural `EPOCH_ADJ` / `EPOCH_NOUN` vocabularies. Surface `LORE` and `QUESTS` later in the same monolith are separate variables in the same historical artifact; extraction must distinguish their scope rather than retaining only the last matching name. Duplicate historical helper declarations also exist, so migrating by first text match is unsafe.

## Ordered integration and acceptance

1. **P0 physical continuity:** enable native plan coverage on supported surface maps, reserve mouths before vegetation/buildings, ensure terrain holes and floor collision agree, prebuild approach chunks with a frame budget. Walk surface → mouth → chamber → same mouth → surface with identical renderer, camera, player, audio session and URL. Verify a cold approach as well as warmed chunks. `Crysis.cave(i)` is a debug teleport and does not prove continuity.
2. **P0 musical continuity:** native crystal/rock/fungus strike routing, expressive input ownership, persistent faceplate harmony and audible/reactive world response. Verify sustained notes release and input remains playable during streaming.
3. **P1 discovery loop:** bring echo/song-shard progression into native quests and world-scoped persistence. Reward a visible/audio change such as a lit passage, restored listening site or richer local music. Surface return and revisit must retain the result.
4. **P1 ecological/civic richness:** restore selected geodes, water features, fauna, useful torches and role-specific inhabitants with bounded populations and stable IDs. Retain current native village/ruin/profile strengths.
5. **P2 long descent:** add branching depth strata, trials, vaults, lava hearts and core journey with lazy deterministic generation. Scope coordinate origin/precision and memory budgets explicitly before claiming legacy-depth parity.

Test at least Earth, one temperate planet, one ice planet and one magma planet, including two different seeds of the same type. Check mouse/touch, follower pathing/headroom, dry cave water exclusion, return after reload, entrance labels fading, high-speed approach, chunk disposal/re-entry, and preservation of private NPC conversations. Record measured frame time/memory and actual browser observations separately from source-inferred suggestions. Keep unresolved matrix rows open in the build queue until their own acceptance checks pass.

## Native migration checkpoint in this change

`island/src/planet/cave-lore.js` now preserves the original 28 dweller lines (elder 10, trader 5, parent 5, worker 4, child 4), nine soul-descent lines, ten vault lines, both 16-word epoch vocabularies and four named milestones. The arrays are recursively frozen. `caveResidentMeta` provides deterministic cave/site/resident IDs and age/activity-appropriate roles; `cavePersona` preserves the resident's name while replacing inappropriate surface biography, and `caveLoreReply` selects actual role lore for relevant questions while leaving actions to the existing shared NPC system.

`cavevillage.js` attaches that metadata to native villagers and transfers ownership to the existing persistent social actor system without duplicate animation/disposal. Conversations pause ambient motion. Children stay near their cave home when a formerly ambient family head joins the player. The village async body builder stops after disposal. Root integration owns talker registration and shared persona/social wiring; this source checkpoint alone is not an end-to-end browser verification claim.

Exact source-extraction parity, immutability, identity determinism, world-seed isolation, role assignment, retained names, removal of surface regional context, lore-topic selection and action fallthrough passed Node assertions. Both changed source modules passed syntax and unused-variable checks.

The parallel native `cave-elements.js` work adds a bounded subset: playable resonance stone triads with a persistent local illuminated-route reward, and contained roost/fly bats where the biome permits. This is not full legacy echo/song-shard expedition parity or the deep core journey; those rows remain open.
